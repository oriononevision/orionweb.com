# ORION — Site web

Landing page premium pour ORION (Vite + React + TypeScript + React Three Fiber).

## Démarrer

```bash
npm install
npm run dev
```

Ouvre [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Stack

- React 19 + Vite
- Framer Motion (entrées / scroll)
- Three.js / React Three Fiber (orbes verre, anneaux, particules)
- Assets IA dans `public/images/`

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build production
- `npm run preview` — prévisualiser le build
